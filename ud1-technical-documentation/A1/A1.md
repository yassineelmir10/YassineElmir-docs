1. **Licencias**

***GNU General Public License v3***

La **Licencia Pública General de GNU** o más conocida por su nombre en inglés **GNU General** **Public License** (o simplemente sus siglas en inglés **GNU GPL**) es una licencia de [derecho de autor](https://es.wikipedia.org/wiki/Derecho%3Cem%3Ede%3C/em%3Eautor) ampliamente usada en el mundo del [software libre ](https://es.wikipedia.org/wiki/Software_libre)y código abierto,\[6\] y garantiza a los usuarios finales (personas, organizaciones, compañías) la libertad de usar, estudiar, compartir (copiar) y modificar el software.

Su propósito es doble: declarar que el software cubierto por esta licencia es libre, y protegerlo (mediante una práctica conocida como [copyleft)](https://es.wikipedia.org/wiki/Copyleft) de intentos de apropiación que restrinjan esas libertades a nuevos usuarios cada vez que la obra es distribuida, modificada o ampliada. Esta licencia fue creada originalmente por [Richard Stallman,](https://es.wikipedia.org/wiki/Richard%3Cem%3EStallman) fundador de la [Free Software Foundation ](https://es.wikipedia.org/wiki/Free%3C/em%3ESoftware%3Cem%3EFoundation)(FSF) para el [proyecto](https://es.wikipedia.org/wiki/Proyecto%3C/em%3EGNU) [GNU.](https://es.wikipedia.org/wiki/Proyecto%3C/em%3EGNU)

***MIT License***

The **MIT License** is a [permissive software license ](https://en.wikipedia.org/wiki/Permissive%3Cem%3Esoftware%3C/em%3Elicense)originating at the [Massachusetts Institute of](https://en.wikipedia.org/wiki/Massachusetts%3Cem%3EInstitute%3C/em%3Eof%3Cem%3ETechnology) [Technology ](https://en.wikipedia.org/wiki/Massachusetts%3Cem%3EInstitute%3C/em%3Eof%3Cem%3ETechnology)(MIT) in the late 1980s. As a permissive license, it puts few restrictions on reuse and has high [license compatibility.](https://en.wikipedia.org/wiki/License%3C/em%3Ecompatibility)

Unlike [copyleft ](https://en.wikipedia.org/wiki/Copyleft)software licenses, the **MIT License** allows reuse within [proprietary software,](https://en.wikipedia.org/wiki/Proprietary_software) provided that all copies of the software or its substantial portions include a copy of the terms of the MIT License and also a copyright notice. In 2015 and from at least 2020 through 2025,\[12\] the MIT License was the most popular software license on [GitHub.](https://en.wikipedia.org/wiki/GitHub)

Notable projects that use the MIT License include the [X Window System,](https://en.wikipedia.org/wiki/X%3Cem%3EWindow%3C/em%3ESystem) [Ruby on Rails,](https://en.wikipedia.org/wiki/Ruby%3Cem%3Eon%3C/em%3ERails) [Node.js,](https://en.wikipedia.org/wiki/Node.js) [Lua,](https://en.wikipedia.org/wiki/Lua) [jQuery,](https://en.wikipedia.org/wiki/JQuery)[.NET,](https://en.wikipedia.org/wiki/.NET) [Angular)](https://en.wikipedia.org/wiki/Angular%3Cem%3E\(web%3C/em%3Eframework), and [React)](https://en.wikipedia.org/wiki/React_\(software).

***Apache License***

The **Apache License** is a [permissive ](http://localhost:46233/Permissive%3Cem%3Esoftware%3C/em%3Elicense)[free-software and free and open source software ](https://en.wikipedia.org/wiki/Free%3Cem%3Eand%3C/em%3Eopen-source%3Cem%3Esoftware)license written by the [Apache Software Foundation ](https://en.wikipedia.org/wiki/The%3C/em%3EApache%3Cem%3ESoftware%3C/em%3EFoundation)(ASF). It allows users to use the software for any purpose, to distribute it, to modify it, and to distribute modified versions of the software under the terms of the license, without concern for [royalties.](https://en.wikipedia.org/wiki/Royalty_payment) The ASF and its projects release their software products under the Apache License. The license is also used by many non-ASF projects.

***BSD 3-Clause License***

**BSD 3-Clause License** are a family of [permissive free software licenses,](http://localhost:46233/Permissive%3Cem%3Esoftware%3C/em%3Elicense) imposing minimal restrictions on the use and distribution of covered software. This is in contrast to [copyleft ](https://en.wikipedia.org/wiki/Copyleft)licenses, which have [share-](https://en.wikipedia.org/wiki/Creative%3Cem%3ECommons%3C/em%3Elicense#Four%3Cem%3Erights) [alike ](https://en.wikipedia.org/wiki/Creative%3Cem%3ECommons%3C/em%3Elicense#Four%3Cem%3Erights)requirements. The original BSD license was used for its namesake, [the Berkeley Software](https://en.wikipedia.org/wiki/Berkeley%3C/em%3ESoftware%3Cem%3EDistribution) [Distribution ](https://en.wikipedia.org/wiki/Berkeley%3C/em%3ESoftware%3Cem%3EDistribution)(BSD), a Unix-like [operating system.](https://en.wikipedia.org/wiki/Operating%3C/em%3Esystem) The original version has since been revised, and its descendants are referred to as modified BSD licenses.

***Mozilla Public License 2.0***

The **Mozilla Public License (MPL)** is a [free and open-source ](https://en.wikipedia.org/wiki/Free%3Cem%3Eand%3C/em%3Eopen-source%3Cem%3Esoftware)[weak copyleft ](https://en.wikipedia.org/wiki/Copyleft#Strong%3C/em%3Eand%3Cem%3Eweak%3C/em%3Ecopyleft)license for most [Mozilla](https://en.wikipedia.org/wiki/Mozilla%3Cem%3EThunderbird) [Foundation software ](https://en.wikipedia.org/wiki/Mozilla%3Cem%3EThunderbird)such as [Firefox ](https://en.wikipedia.org/wiki/Firefox)and [Thunderbird.](https://en.wikipedia.org/wiki/Mozilla%3C/em%3EThunderbird) The MPL is developed and maintained by Mozilla, which seeks to balance the concerns of both open-source and proprietary developers. It is [distinguished](https://en.wikipedia.org/wiki/Comparison%3Cem%3Eof%3C/em%3Efree%3Cem%3Eand%3C/em%3Eopen-source%3Cem%3Esoftware%3C/em%3Elicenses) [from others ](https://en.wikipedia.org/wiki/Comparison%3Cem%3Eof%3C/em%3Efree%3Cem%3Eand%3C/em%3Eopen-source%3Cem%3Esoftware%3C/em%3Elicenses)as a middle ground between the [permissive software ](https://en.wikipedia.org/wiki/Permissive%3Cem%3Esoftware%3C/em%3Elicense)[BSD-style ](https://en.wikipedia.org/wiki/GNU%3Cem%3EGeneral%3C/em%3EPublic%3Cem%3ELicense)licenses and the [GNU](https://en.wikipedia.org/wiki/BSD%3C/em%3Elicenses) [General Public License.](https://en.wikipedia.org/wiki/BSD%3C/em%3Elicenses) As such, it allows the integration of MPL-licensed code into proprietary codebases, as long as the MPL-licensed components remain accessible under the terms of the MPL.

***Git***

Git es un **sistema de control de versiones distribuido** que permite gestionar y realizar un seguimiento de los cambios realizados en un proyecto. Es un proyecto **Open Source** y su código fuente está disponible para los usuarios. Git se distribuye bajo la licencia **GNU General Public License** **versión 2 (GPLv2)**, por lo que puede utilizarse de forma gratuita. Esta licencia también permite estudiar, modificar y redistribuir el software respetando las condiciones establecidas por la GPLv2.

***GitHub***

GitHub es una **plataforma de desarrollo y colaboración** que permite alojar repositorios, gestionar proyectos y trabajar de forma colaborativa. El uso de GitHub está regulado por sus **GitHub Terms of** **Service**, y la propia plataforma y su servicio son propiedad de GitHub. GitHub ofrece planes gratuitos, aunque también dispone de planes y funciones de pago. El código fuente de los proyectos alojados en

GitHub puede ser público o privado dependiendo de la configuración y de la licencia elegida por el propietario del proyecto. Sin embargo, **el código fuente de la propia plataforma GitHub.com no** **está disponible como un proyecto Open Source completo**
